# i18n

The platform ships **English and Spanish**; English is the default.

## Dictionaries

`src/lib/dicts.ts` exports:

- `dicts.en` / `dicts.es` — flat key→string maps (e.g. `nav.journals`,
  `home.cta.body`, `workflow.published`).
- `getInitialLocale()` — client-side resolution: `localStorage["caribe_locale"]`
  → cookie `caribe_locale` → `navigator.language` prefix → `"en"`.
- `getServerLocale()` — server-side (uses `next/headers` cookies), returns the
  same `Locale` union for deterministic SSR.

## Storage & propagation

- `LangSwitch` (navbar) writes both `localStorage` and the cookie
  `caribe_locale` (`max-age=1y`, `SameSite=Lax`) — this keeps Server
  Components and client state in sync across navigations.
- The root `layout.tsx` reads the cookie to render localized titles and lets
  `LocaleProvider` hydrate from the same source (no hydration mismatch;
  `suppressHydrationWarning` on the html element).
- Consumers: `useLocale()` (client) returns `{locale, setLocale, dict}`;
  server pages call `getServerLocale()` and pass `locale` down or branch
  directly (e.g. `title_es` fields, localized dates).

## Content model

Bilingual fields live in the data model and are rendered conditionally:

- `articles.title_es`, `abstract_es`, `keywords_es` (fallback to EN)
- `journals.title_es`, `description_es`
- `sections.name_es`
- `countries.name_es`
- Editorial copy (status labels, prompts) comes from the dictionaries.

## Labelling policy

- UI chrome (nav, buttons, statuses, empty states) → dictionaries.
- Article/domain text → content fields, shown with `locale === "es"` fallback
  chains.
- Dates: `toLocaleDateString(locale === "es" ? "es" : "en-US", ...)`.
- The default locale (English) always remains authoritative on the wire —
  browsers and crawlers without the cookie get English SSR.

## Adding a locale

1. Add keys to `dicts.es` (or a new `dicts.xx`) keeping the exact same keys.
2. Extend the `Locale` union and the cookie/localStorage readers.
3. Add `name_xx` content columns where the data model warrants it.
